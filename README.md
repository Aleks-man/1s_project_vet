# Вектор учета

Фронтенд-проект на Vite, React и TypeScript для сайта по продаже, внедрению и сопровождению 1С в Симферополе, Севастополе и Крыму.

## Команды

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Этапы разработки

1. `chore: initialize project` - Vite React TypeScript, базовые SEO-файлы и стартовая главная.
2. `feat: structure homepage` - декомпозиция главной на компоненты, данные каталога, формы заявок.
3. `feat: add catalog pages` - маршруты и SEO для страниц программ, сервисов и оборудования.
4. `feat: add backend api` - Express API для заявок, каталога и админских данных.
