# Вектор учета

Фронтенд-проект на Vite, React и TypeScript для сайта по продаже, внедрению и сопровождению 1С в Симферополе, Севастополе и Крыму.

## Команды

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Этапы разработки

1. `chore: инициализация проекта` - Vite React TypeScript, базовые SEO-файлы и стартовая главная.
2. `feat: главная страница` - декомпозиция главной на компоненты, данные каталога, формы заявок.
3. `feat: каталог и страницы услуг` - маршруты, SEO для страниц программ, сервисов и оборудования.
4. `feat: серверная часть` - Express API для заявок, каталога и админских данных.
